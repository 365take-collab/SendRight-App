## ■ 支配的感情

| 項目 | 内容 |
|------|------|
| 支配的感情 | **屈辱（#9）** |
| 感情の核心 | 「自分だけができない」という恥ずかしさ |
| 痛みの深さ | 個人的痛み（誰にも言えない、秘密にしたい） |

### 感情シーン
```
深夜1時、ベッドの中でスマホを握りしめている。
マッチしたばかりの女性からLINEが来た。「今日何してた？」
たった6文字。なのに、何て返せばいいかわからない。
「仕事してた」じゃつまらない。「○○行ってきた」は自慢っぽい？
30分経った。既読をつけてしまったから、返信しないわけにいかない。
でも何を送っても正解がわからない。
友達はこんなことで悩まない。なんで自分だけこんなに苦手なんだ…。
```

### 痛みの漏斗分析
```
L1 表面: 「何て返せばいいかわからない」「既読スルーされた」
L2 個人: 返信を考えるのに30分〜1時間、マッチしてもフェードアウト
L3 感情: 屈辱、無力感、恐怖
L4 最悪: マッチングアプリに月5,000円払い続けても永遠に会えない
L5 確定: 「自分だけができない」という屈辱感が最も深く持続的
```

## ■ Dominant Selling Idea（DSI）

| 項目 | 内容 |
|------|------|
| DSI | 「700人の女性を口説いた男のメッセージ術が、24時間あなたの横にいる」 |
| メカニズム名 | **700人斬りAIコーチ** |
| 推薦理由 | 具体的な数字「700人」のインパクト、実績による権威性、24時間対応の差別化、ストーリーとの完全一致 |
| A/Bテスト候補 | 「10秒3択メソッド」（機能ベースアプローチ） |

### DSI 6条件チェック
| 条件 | 合否 | 理由 |
|------|------|------|
| 感情直結 | ○ | 「24時間味方がいる」で屈辱感を解消 |
| 一文で言える | ○ | 「700人斬りの経験が24時間横にいる」 |
| 反論を生む | ○ | 「本当に700人？」と思わせる |
| 独自性（Ownership） | ◎ | 「700人斬りAI」= Send Rightと認知される |
| 証明可能 | ○ | 創業者の実績として証明 |
| 1つに絞れている | ○ | 「700人の経験 × 24時間」の1軸 |

## ■ ブランドストーリー骨格

| 要素 | 内容 |
|------|------|
| 主人公 | 創業者（元ナンパ師・700人斬り達成） |
| 痛みの原体験 | 最初は自分もメッセージが下手。既読スルーされまくり |
| 転換点 | 700人以上とのやり取りで「何を送れば返ってくるか」完全に習得 |
| 講師としての限界 | 生徒が「今この返信どうすればいい？」と聞いてきても、すぐに答えられない |
| 使命 | 「いつでも、どんな時でも、すぐに正解を教えてくれる存在」を作る |

### 感情アーク
```
屈辱（自分もできなかった）
  → 習得（700人とのやり取り）
    → 教える側へ（講師業）
      → 課題発見（24時間対応できない）
        → 解決（AIを作った）
          → 希望（あなたも変われる）
```

## ■ Dimensionalizeされたベネフィット（TOP 3）

### ベネフィット1: もう悩まない
| 階層 | 内容 |
|------|------|
| 抽象 | 返信を考えなくていい |
| 具体的変化 | 30分悩んでいたのが10秒で3候補出る |
| 五感体験 | スマホをタップした瞬間、3つの選択肢が並ぶ画面を見る |

### ベネフィット2: 会話が続く
| 階層 | 内容 |
|------|------|
| 抽象 | 会話が続くようになる |
| 具体的変化 | 1週間続かなかった会話が3週間続く |
| 五感体験 | 毎日通知音が鳴る。開くと彼女からの返信がある |
| 感情的意味 | 「俺でも会話できる」という自信 |

### ベネフィット3: デートに誘える
| 階層 | 内容 |
|------|------|
| 抽象 | デートに誘えるようになる |
| 具体的変化 | マッチから初デートまでの成功率UP |
| 五感体験 | カフェで向かい合って座っている自分を想像する |
| 感情的意味 | 「ついにここまで来た」という達成感 |

## ■ トーン & ボイス

| 項目 | 内容 |
|------|------|
| 感情トーン | 希望系 → 変化・逆転トーン |
| 話者の立場 | 同じ経験者（かつて自分もできなかった） + 先輩 |
| 口調 | 堅すぎず、フレンドリー。「男同士の会話」感 |

### 禁止表現
- ターゲットを馬鹿にする表現（「モテない君へ」等）
- 過度な煽り（「今すぐ買わないと人生終わる」等）
- 性的な表現（規約違反リスク）
- 「絶対」「100%」等の断定表現

## ■ 感情トリガー素材

### 共感トリガー（「わかる」と思わせる）
1. 「今日何してた？」に30分悩む
2. 既読つけちゃったから返信しないと、でも何送っていいかわからない
3. 友達はこんなことで悩まない
4. マッチしても会話が続かない
5. デートに誘うタイミングがわからない

### 痛みトリガー（感情を増幅させる）
1. 「自分だけができない」→自己否定
2. 「マッチングアプリに毎月5000円払ってるのに会えない」→金銭的損失
3. 「このまま一人で歳を取っていく」→将来への不安
4. 「恋愛講師に聞きたいけど、深夜1時に対応してくれない」→解決策の不在

### 希望トリガー（解決の光を見せる）
1. 「30分が10秒になる」→劇的な時間短縮
2. 「700人斬りの経験が24時間横にいる」→最強の味方
3. 「俺も昔はできなかった。でも今は教える側」→変化の可能性
4. 「正解を知ってれば、誰でもできる」→努力不要の安心感

### 行動トリガー（今すぐ動かす）
1. 「7日間無料」→リスクゼロ
2. 「今日から返信で悩まない」→即時性
3. 「クレジットカード不要」→ハードル除去
4. 「月5000円の課金、無駄にしてない？」→機会損失

## ■ 「敵」の設定

| 敵 | 内容 |
|-----|------|
| 隠された真実 | 「返信の正解」は学校で教わらない。知ってるか知らないかだけの差 |
| 業界の嘘 | 「恋愛は才能」→ 違う、正解を知っているかどうか |
| 間違った常識 | 「たくさん話しかければいい」→ 違う、何を送るかが全て |
| 構造的問題 | 恋愛講師は24時間対応できない |

## ■ 用途別ガイドライン

### 広告コピー向け
- **フック方向性**: 共感型（Problem Aware向け）
- **ボディ**: 「30分→10秒」のBefore/After または 700人の権威性
- **CTA**: 「7日間無料で試す」「今すぐ始める」

### LP向け
1. ヘッドライン → DSI（700人斬りAIコーチ）
2. オープニング → 感情シーン（深夜のベッド）
3. 問題の増幅 → 「自分だけができない」屈辱感
4. 敵の設定 → 「正解を教えてもらえなかっただけ」
5. 転換点 → ブランドストーリー
6. ソリューション → 機能説明 + Dimensionalizeされたベネフィット
7. 差別化 → ChatGPTとの比較
8. 証拠 → ユーザーの声
9. 料金 → 価値の比較（マッチングアプリ月額 vs Send Right）
10. CTA → 「7日間無料」+ リスクリバーサル

### SNS投稿向け
- **トーン**: 変化・逆転トーン（希望系）
- **1行目**: 共感トリガー（「返信で30分悩んだことある人だけ見て」）
- **ストーリー**: 短縮版ブランドストーリー
- **CTA**: 「プロフにリンクあり」（軽いCTA）
