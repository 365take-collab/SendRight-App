## 使い方

1. HTMLファイルをブラウザで開く
2. ブラウザの開発者ツールでスクリーンショットを撮る
   - Chrome: 右クリック → 検証 → Cmd+Shift+P → "Capture node screenshot"
3. または、デザインツール（Figma/Canva）にコピー

## 広告パターン

### A: 痛み共感型「また既読スルー…」
- **ターゲット**: 既読スルーで悩んでいる人
- **フック**: 痛みへの共感から入る
- **CTA**: 7日間無料で試す

### B: ストーリー型「700人斬りのナンパ師」
- **ターゲット**: 権威性に反応する人
- **フック**: 開発者のストーリーで信頼を獲得
- **CTA**: 7日間無料で試す

### C: Before/After型「30分→10秒」
- **ターゲット**: 具体的な数字に反応する人
- **フック**: ビフォーアフターの対比
- **CTA**: 7日間無料で試す

## A/Bテスト計画

### Phase 1: フック検証
- A vs B vs C を同時出稿
- CTRで勝者を決定

### Phase 2: CTA検証
- 勝ちパターン × 複数CTA
  - 「7日間無料で試す」
  - 「今すぐ始める」
  - 「無料で使ってみる」

### Phase 3: フォーマット検証
- 静止画 vs 動画
- フィード vs ストーリーズ vs リール

## 注意事項

- 実際の出稿前にMeta広告ポリシーを確認
- 「恋愛」「出会い」関連は審査が厳しい場合あり
- 過度な約束（「100%成功」等）は避ける
