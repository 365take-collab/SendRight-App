### 感情シーン
> 深夜1時、ベッドでスマホを握りしめている。
> マッチした女の子からの返信が来た。「今度どこか行きたいですね〜」
>
> どう返せばいい？
> 「いいですね！」だけじゃ弱い気がする。
> かといって、いきなり具体的な店を提案するのも重い？
>
> 30分かけて文章を考える。送信ボタンを押す瞬間、心臓がバクバクする。
>
> 翌朝、既読がついている。返信はない。
>
> 「また失敗した…」
> 会社で何も手につかない。友達には絶対言えない。こんなことで悩んでるなんて。

## Dominant Selling Idea（USP）

### メイン主張
> **「もう返信で恥をかかない。恋愛のプロが10秒であなたの代わりに考える」**

### メカニズム名
**プロ代行AI**

### 6条件チェック

| 条件 | 評価 | 理由 |
|------|------|------|
| 感情直結 | ◎ | 「恥をかかない」が屈辱に直結 |
| 一文で言える | ○ | 感情+解決が1文 |
| 反論を生む | ○ | 「プロって誰？」「本当に恥かかない？」 |
| 独自性（Ownership可能） | ○ | 「恥」に言及するサービスは少ない |
| 証明可能 | ○ | 成功事例、解説の質で証明 |
| 1つに絞れている | ○ | 「恥をかかない」に集中 |

**スコア: 5.5/6**

### A/Bテスト候補
「10秒正解メソッドで、返信に悩む30分を一瞬で終わらせる」

### Specialization運用ルール（今後の生成用）
- 新カテゴリを作ったときは、Specializationを「[カテゴリ名]で唯一」で止める（機能説明を1文に詰め込まない）
- 具体機能は別行で書く（例: 「スクショを貼るだけ」「5秒で3候補」「文脈を読んで提案」）
- SendRightのみブランドストーリーは例外扱いにし、開発者実績（700人斬り）を維持する

## ブランドストーリー骨格

| 要素 | 内容 |
|------|------|
| 主人公 | 開発者（700人斬りのナンパ師） |
| 痛みの原体験 | かつては自分も全く女性と話せなかった。数え切れない既読スルーと拒絶を経験 |
| 転換点 | 試行錯誤の末、「正解のパターン」が存在することに気づいた。それを体系化して700人と関係を築いた |
| 使命 | 自分が何年もかけて身につけた「正解」を、AIに学習させることで、誰でも一瞬で使えるようにしたい |

### 感情アーク
```
屈辱（全く話せない過去）
  → 試行錯誤（数え切れない失敗）
    → 気づき（正解のパターンは存在する）
      → 成功（700人斬り）
        → 使命（この正解を全員に届けたい）
```

### ストーリーの強み
- **権威性**: 700人という実績が「この人の言うことは正しい」という信頼を生む
- **共感**: かつては自分も話せなかった→ターゲットと同じスタート地点
- **希望**: 「俺でもできるようになった。だからあなたもできる」

## 用途別ガイドライン

### LP / セールスレター向け
```
推奨構成:
1. ヘッドライン → 「また既読スルー…」を終わらせる
2. オープニング → 感情シーン or ブランドストーリーで掴む
3. 問題の増幅 → 痛みトリガー素材を使用、「敵」を明確にする
4. 転換点 → プロ代行AIを提示
5. ソリューション → Dimensionalizeされたベネフィット展開
6. 証拠 → 成功事例、Before/After
7. オファー → 7日間無料トライアル、リスクリバーサル
8. CTA → 行動トリガー素材を使用
```

### 広告コピー向け
```
推奨フック方向性（Problem Aware向け）:
- 共感型フック → 「また既読スルー…」系
- 痛み提示フック → 「返信で悩む30分」系

ボディ方向性: ベネフィット1（時間短縮）を使用
CTA方向性: 「7日間無料」「今夜から使える」
```

### SNS投稿向け
```
推奨トーン: 味方・救済トーン
1行目の方向性: 共感トリガーから開始
ストーリー素材: ブランドストーリー骨格を短縮版で使用
CTA: プロフリンクへ誘導
```
