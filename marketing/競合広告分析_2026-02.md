## 直接競合の不在

**重要な発見**: 「AI返信」「メッセージ生成」系の直接競合広告はMeta Ad Libraryで見つからなかった。

**意味:**
1. **ブルーオーシャン**: 競合がまだ広告を出していない
2. **先行者利益**: 今広告を出せばカテゴリを占有できる可能性
3. **教育コストが必要**: 「AIで返信を作る」という概念を説明する必要あり

## 広告パターン分析

### パターン1: 価格訴求型（メンズスキンクリニック）
```
フック: [商品名]が[具体的価格]
本文: [メリット]、[限定感]
CTA: 詳しくはこちら
```
**SendRightへの適用:**
> 「返信AIが月額6,980円。7日間無料で試せる」

---

### パターン2: ストーリー型（宮澤ケイ）
```
フック: [衝撃的な一言 / 意外性]
本文: [Before状態] → [転換点] → [After状態]
CTA: 続きを見る
```
**SendRightへの適用:**
> 「100人に既読スルーされた男が、たった1つの変化で彼女を作った話」

---

### パターン3: 痛み共感型（恋愛コンサル系）
```
フック: [ターゲットの痛み / 悩み]
本文: [共感] → [原因の指摘] → [解決策の提示]
CTA: 無料で試す
```
**SendRightへの適用:**
> 「返信を考えすぎて、気づいたら深夜2時。その悩み、10秒で解決します」

## SendRight広告への推奨

### 推奨パターン: ストーリー型 + 痛み共感型のハイブリッド

**理由:**
1. 直接競合がいないため、「教育」が必要
2. ストーリーで興味を引き、痛みで共感を得る
3. 700人の実績という強い権威性を活かせる

### 推奨フォーマット

**動画広告（15-30秒）:**
```
[0-3秒] フック: 「また既読スルー…」
[3-10秒] 痛み: 返信に悩む男性の日常
[10-20秒] 転換: 「正解は存在する」
[20-25秒] 解決: SendRightのデモ画面
[25-30秒] CTA: 「7日間無料」
```

**静止画広告:**
```
メイン画像: スマホ画面（LINEの会話 → SendRightの3候補）
ヘッドライン: 「また既読スルー…」を終わらせる
本文: 700人斬りのナンパ師が教える「正解」を、AIが10秒で
CTA: 7日間無料で試す
```
