## 動画広告（15秒版・30秒版）

### 15秒版: 痛み→解決の最短ルート

```
[0-3秒] フック
  画面: スマホを握りしめる手（暗め）
  テキスト: 「また既読スルー…」
  ナレーション: なし（テキストのみ）

[3-7秒] 痛みの増幅
  画面: 深夜のベッド、スマホの光
  テキスト: 「返信を考えて深夜2時」
  
[7-12秒] 解決策
  画面: SendRightの画面（3候補が表示される）
  テキスト: 「正解を10秒で」「3つから選ぶだけ」
  
[12-15秒] CTA
  画面: ロゴ + CTAボタン
  テキスト: 「7日間無料」
  ナレーション: 「センドライト」
```

### 30秒版: ストーリー型

```
[0-3秒] フック
  画面: LINEの通知（女性からのメッセージ）
  テキスト: 「今度どこか行きたいですね〜」
  
[3-8秒] 痛み
  画面: 男性がスマホを見つめて悩む
  テキスト: 「どう返せばいい？」「30分経過…」
  
[8-12秒] 最悪の結果
  画面: 翌朝、既読マーク
  テキスト: 「また既読スルー」
  
[12-17秒] 転換点
  画面: SendRightのロゴ
  テキスト: 「正解は存在する」
  ナレーション: 「正解は、存在する」
  
[17-25秒] 解決策デモ
  画面: SendRightの使用デモ
  - メッセージを貼り付け
  - 3候補が表示
  - 1つを選択
  テキスト: 「10秒で3つの正解」「選ぶだけ」
  
[25-30秒] CTA
  画面: ロゴ + 7日間無料
  テキスト: 「今夜の返信から使える」
  ナレーション: 「センドライト、7日間無料」
```

## A/Bテスト計画

### Phase 1: フック検証（1週間）

| バリエーション | フック |
|--------------|--------|
| A | 「また既読スルー…」 |
| B | 「返信に30分悩んでるやつ、見て」 |
| C | 「100人に既読スルーされた男が〜」 |

**指標**: CTR（クリック率）
**勝者**: CTR最高のフックを採用

### Phase 2: フォーマット検証（1週間）

| バリエーション | フォーマット |
|--------------|------------|
| A | 静止画（パターンA） |
| B | 動画15秒 |
| C | 動画30秒 |

**指標**: CVR（コンバージョン率）
**勝者**: CVR最高のフォーマットに予算集中

| バリエーション | ターゲット |
|--------------|-----------|

| C | 類似オーディエンス（登録者） |
